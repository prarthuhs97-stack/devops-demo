
# DevOps Demo Application

A Java Spring Boot REST API developed as part of a DevOps self-learning assignment.

## Technologies Used
- Java 21
- Spring Boot
- Maven
- Git and GitHub
- JUnit 5

## Available Endpoints
- GET / - Welcome message
- GET /health - Application health status
- GET /api/message - JSON message

## Testing
Run automated tests using:

./mvnw clean test
